Write YAML atomically: temp file in the same directory, then rename.

A plain fs::write truncates first, so any reader landing in that window sees an empty or half-written file and falls back to minimal_run_metadata — which reports the run as CRASHED. With the dashboard polling while the engine writes every 500ms, that window gets hit.
