Write the multi-run interactive.ipynb into the experiment directory.

Deliberately always the built-in default: --notebook-template does not apply here. A multi-run notebook has no single run, so {{run_dir}}, {{run_name}} and {{project}} have no value to take, and a useful shared template would need a different placeholder set (a {{runs}} list, and a rule for rendering it) — a separate design, not a wider version of this one. Recorded in docs/content/reference/cli.md.

The staleness contract is shared: the built-in content includes the run names, so adding a run refreshes an unedited notebook, and an edited one is still never overwritten.
